# Paradi Web Privacy Policy

This repository contains the Privacy Policy for the Paradi Group Management Dashboard, a Roblox OAuth 2.0 application used for group management purposes.

## Documentation

- **[Privacy Policy](PRIVACY_POLICY.md)** - Complete privacy policy for users of the Paradi Group Management Dashboard

## About

The Paradi Group Management Dashboard is a Roblox OAuth 2.0 application that enables group administrators to efficiently manage their Roblox groups. This Privacy Policy outlines how we collect, use, and protect user data in compliance with applicable privacy laws including GDPR, COPPA, and CCPA.

## Key Points

- **Purpose**: Group management functionality only
- **Data Collection**: Only essential data collected through Roblox OAuth 2.0
- **No Marketing**: We do not use your data for marketing or sell it to third parties
- **User Rights**: Users can access, modify, or delete their data at any time
- **Security**: Industry-standard encryption and security measures
